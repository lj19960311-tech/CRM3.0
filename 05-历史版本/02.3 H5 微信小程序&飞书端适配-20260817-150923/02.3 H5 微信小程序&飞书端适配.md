## 2 窄屏交互适配规范

### 2.1 全局

| 项 | 规则 |
| --- | --- |
| 断点 | 手机 <768px 单列；平板 ≥768px 沿用 PAD 布局（截图中的形态） |
| 导航 | 左上角汉堡 → 抽屉式侧栏（专家技能/我的文件/客户笔记/智能体/历史）；PC 的常驻侧栏在手机端不常驻 |
| 输入区 | 底部固定。左「+」（文件/选专家），中输入框，右麦克风。发送按钮在有内容时替换麦克风位置 |
| 键盘唤起 | 输入区上推，会话区自动滚动到底；键盘收起不改变滚动位置 |
| 免责声明 | 输入框下方常驻单行，字号降一级 |

### 2.2 专家卡与推荐问题

- 专家卡：**横滑卡片流**，一屏露出 1到2 张（露出右侧卡片边缘暗示可滑）。分类 tab 横滑吸顶。

- 推荐问题：竖排单列，每条独占一行，**长文案不截断改为两行**

- 「换一批」放在列表末尾，不占顶部空间。

### 2.3 产出物

- 会话内展示为**紧凑卡片**（图标 + 名称 + 类型 + 时间），不展开预览。

- 点击 → 全屏详情页，底部操作条：分享 / 发邮箱 / 收藏（分享见另一个需求文档）。

## 6 埋点差异【同步至 08】

公共参数 `client` 枚举扩展：`pc` / `pad` / `wx_miniapp` / `feishu`。

新增事件：
| 事件 | 触发场景 | 埋点方 | 关键参数 |
| --- | --- | --- | --- |
| share_click | 点击转发/分享 | 前 | artifact_id、channel（微信好友/飞书会话/分享链接） |
| share_result | 分享结果 | 后 | status、err_code |

**要看的两个数**：

- **移动端占比**

- **分享点击率**——哪类产出物 销售真的使用
