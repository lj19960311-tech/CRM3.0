# 上传文件

> 本功能的 Skill 分工、Tool 设计、调用编排及 Website 使用规则统一遵循《物流产品专家 prd》的规范，研发不在本功能内另建一套规则，仅按文件上传与销售材料分析场景接入所需能力。

## 一. 项目背景

保留文件解析和物流解决方案分析报告生成功能，新增任务意图判断与澄清机制，并将固定生成报告扩展为可按用户指令完成材料总结、公司痛点分析、销售建议、拜访准备等；用户仅上传文件时先澄清具体目的，用户输入明确时以本轮指令为准。

## 二. 功能目标

| 场景 | 处理方式 |
| --- | --- |
| 用户仅上传文件 | 先澄清任务，不默认生成报告（可参考demo) |
| 用户同时输入明确任务 | 优先执行本轮输入；与材料无关时不分析文件 |
| 当前会话已有明确任务 | 将新文件用于当前任务 |
| 生成分析结果 | 支持报告、总结、痛点分析、核心内容提取、拜访建议等任务生成 |

## 三. 唤起方式与能力边界

### 3.1 唤起方式

| 1. 用户点击“上传文件”。<br>2. 用户从本地选择一份或多份材料。<br>3. 文件上传成功后，以文件卡片形式展示在输入框内。<br>4. 用户可以直接发送文件，也可以补充文字指令后再发送。<br>5. 用户只发送文件时进入任务澄清；用户同时输入明确指令时直接执行对应任务。 | ![上传文件界面截图](../04-图片资源/上传文件_assets/上传文件-界面截图.png) |

### 3.2 能力边界

| 边界类型 | 说明 |
| --- | --- |
| 文件范围 | 支持 PDF、PPT／PPTX、DOC／DOCX；单次最多 3 个、合计不超过 50MB。上传文件仅在当前会话临时使用，不保存到“我的文件”。 |
| 任务范围 | ① 用户本轮输入优先；② 仅上传文件时先澄清；③ 输入与材料无关时直接执行用户任务，不强制分析文件。 |
| 数据与权限 | 只读取当前用户有权限访问的文件和内部数据，不访问或泄露其他用户及无权限数据。 |
| 事实与联网 | 客户事实须来自材料、工商／内部数据或可靠互联网公开信息，并展示来源；企业信息、企业痛点、行业背景和行业画像允许联网查询，具体见【物流产品专家PRD】中的规则。 |
| 企业确认 | 企业主体唯一时可关联“企业地图”或“三查一宝”（优先使用企业地图）；存在多个候选时，先由用户确认主体再进行语义查询。 |
| 产品与案例、解决方案 | 产品、案例和通用解决方案只使用内部数据；查询不到时，使用降级查询，不通过联网补齐。 |
| 操作与输出 | 本功能只读，不修改业务数据或发起流程；支持在线预览和导出 PDF，AI 生成报告后保存到“我的文件”，不生成正式报价、合同或法律文件。 |

### 3.3 用户输入与澄清

| 使用场景 | 系统处理 | 回复示例（具体回复根据文件生成） |
| --- | --- | --- |
| 仅上传一份或多份文件，没有文字指令 | 读取材料内容后展示 Follow up，选择前不输出总结或报告 | “材料已读取，你希望我：①生成物流解决方案分析报告；②提取材料中的核心信息；③详细总结文档内容。 |
| 用户明确说“生成客户物流解决方案分析报告” | 不澄清，直接生成报告 | 进入报告生成 |
| 用户明确说“总结材料并分析痛点” | 不澄清，直接执行 | 输出材料总结和痛点分析 |
| 文档 A 与文档 B 存在会影响任务结果的冲突 | 暂停原任务，单独展示“冲突 Follow up”；用户确认前不得继续任务 | 例如：“文档 A 显示公司 A 属于物流行业，文档 B 显示公司 A 属于产品平台行业，两份材料对公司行业定位的描述不一致。请确认本次以哪种定位为准：物流行业／产品平台行业。”用户选择后再继续原任务 |
| 用户上传文件，同时输入与材料无关的明确任务，例如“查询张三的线索都有哪些” | 以文字任务为准，直接调用对应skills查询并返回张三的线索；本轮不解析、不分析文件，也不询问文件用途 | 正常展示张三的线索查询结果；已上传文件保留在当前会话中，用户后续需要时可继续使用 |
| 用户指定的客户与材料中的企业不一致 | 确认分析对象 | 材料提及甲公司，但您输入的分析对象为乙公司，请确认分析对象：甲公司／乙公司（参考[物流产品专家]中选择多个企业的交互） |
| followup questions | 根据用户query 生成推荐问题，点击后，可以直接发送 | 默认候选任务为“生成物流方案分析报告、总结文档内容、提取材料中的核心信息”；可根据招标文件、合同、会议纪要等材料类型动态替换。 |

## 四. 交互与任务类型

### 4.1 首页上传交互

| 场景 | 触发 | 页面 | 点击／发送后 |
| --- | --- | --- | --- |
| 首页默认态 | 未上传文件 | ① 输入框左下方展示“上传文件”；<br>② 鼠标移入时展示【ppt/word/pdf，合计≤50M,最多3个】 | 点击“上传文件”打开本地文件选择 |
| 文件已选择 | 用户选择文件成功 | 输入框内展示文件卡片及删除入口及示例问题；隐藏“也可以直接问“ | 可删除文件、输入任务或直接发送 |
| 文件 Follow up | 输入框中存在文件 | 文件卡片下展示“生成物流解决方案分析报告”；“提取材料中的核心信息”；“详细总结文档内容”等，可按材料类型调整 | 点击后直接发送文件并执行对应任务 |
| 仅发送文件 | 文件存在且文字为空 | 对话区展示任务澄清 | 用户选择后立即执行 |
| 文件加明确材料任务 | 文件存在且输入材料相关任务 | 不澄清，直接进入材料解析和任务执行 | 展示对应任务结果 |
| 文件加无关任务 | 文件存在且输入与材料无关的任务 | 不展示材料解析过程，不发起文件用途澄清 | 直接返回文字任务结果；文件继续保留，但不自动再次展示 Follow up |

### 4.2 生成客户物流分析报告

仅在用户明确要求、当前会话已确认生成报告，或用户在澄清选项中选择“生成物流解决方案分析报告”时生成，不作为文件上传后的默认任务。

| 报告板块 | 是否必须 | 内容与数据来源 | 信息不足时 |
| --- | --- | --- | --- |
| 客户洞察 | 必须 | 总结企业主体的工商数据、客户信息和客户画像相关的信息，不超过500个字 | 主体不明时先确认；数据缺失时明确说明，不根据工商或公开信息推断预算和决策关系 |
| 核心业务痛点 | 有可靠材料时输出 | 材料中明确出现的业务问题、影响、需求及文件位置 | 没有明确证据时不展示 |
| 推荐产品组合 | 有可靠匹配时输出 | 根据已确认痛点和业务场景查询正式产品库，说明产品、解决的问题和推荐原因 | 无匹配时不展示，不编造产品 |
| 相似案例 | 有可靠匹配时输出 | 从系统的案例库匹配相同类型、相似场景，说明相似点及销售价值 | 无匹配时不展示，不编造案例 |
| 通用解决方案 | 有明确场景时输出 | 从系统的通用解决方案库中匹配 | 无匹配时不展示；不承诺无法验证的收益、比例或周期 |
| 下次拜访建议（本次新增） | 必须 | 建议给出拜访目标、建议参会角色、沟通顺序、重点问题、可展示的产品／案例以及希望客户确认的下一步动作 | 信息不足时将转换为可直接询问客户的问题 |
| 总结分析 | 必须 | 综合客户信号、行业背景、痛点、产品、案例和商机状态，说明优先切入点及整体跟进策略 | 材料不足时降低分析深度，并明确还需补充的信息 |

报告生成后支持在线预览和导出 PDF。报告中的产品组合和相似案例和通用解决方案可以点击之后，在线预览。

### 4.3 其他任务输出

> 下表仅为常见任务示例，用于帮助算法理解可能的用户意图，不代表系统只能处理这些任务；用户可以基于材料提出其他合理需求。表中“输出形式”仅为建议，实际输出应根据用户指令、材料类型和有效信息动态调整。

| 任务场景 | 触发 | 输出内容 | 后续交互 |
| --- | --- | --- | --- |
| 材料总结 | 用户选择或输入“总结材料” | 按文档结构或主题完整总结背景、主要内容、关键数据、结论和待办 | 可要求缩写、展开某章节或追问具体内容 |
| 核心信息摘要 | 用户选择或输入“提取核心信息” | 简明展示核心结论、关键事实、重要数据、风险、待办和时间节点 | 可要求展开某项信息或查看详细总结 |
| 公司痛点分析 | 用户选择或输入“分析公司痛点” | 按“痛点、材料证据、业务影响、信息类型、待确认问题”输出；行业推断标为“待验证” | 可继续生成销售建议或拜访问题 |
| 销售建议 | 用户选择或输入“给出销售建议” | 可包含优先沟通痛点、产品切入点、可引用案例、首次沟通问题和下一步动作 | 可继续生成拜访准备或客户话术 |
| 拜访准备 | 用户选择或输入“整理拜访问题／准备” | 可包含拜访目标、谈话顺序、问题清单、待验证信息和期望确认的下一步动作 | 可继续调整拜访对象或沟通重点 |

## 五. 异常与降级

| 异常 | 系统处理 | 前端提示话术 |
| --- | --- | --- |
| 文件格式不支持 | 阻止该文件上传 | “暂不支持该文件格式，请上传 PDF、PPT、PPTX、DOC 或 DOCX 文件。” |
| 文件数量超过限制 | 保留限制内文件，阻止超出部分 | “单次最多上传 3 个文件，请删除部分文件后重试。” |
| 文件总大小超过限制 | 阻止导致超限的文件 | “本次上传文件合计不能超过 50MB，请压缩文件或减少文件数量后重试。” |
| 文件上传失败 | 保留其他已成功文件，失败文件允许重试 | “《文件名》上传失败，请检查网络后重试。” |
| 文件加密或损坏 | 标记该文件解析失败 | “《文件名》无法读取，文件可能已加密或损坏，请上传可正常打开的版本。” |
| 部分文件解析失败 | 使用成功文件继续处理，并列出失败文件 | “已读取 X 个文件；《文件名》解析失败。本次结果仅基于成功读取的文件生成。” |
| 全部文件解析失败 | 终止材料任务，允许重新上传 | “这些文件暂时无法读取，请检查文件后重新上传。” |
| 文件临时上下文已失效 | 不继续执行依赖原文件的任务，提供重新获取文件的入口 | “原文件已失效，请重新上传后继续。” |
| 企业主体不唯一 | 暂停企业数据查询和客户报告生成，展示候选企业 | “材料中识别到多个可能的企业，请确认本次需要分析的企业。” |
| 材料没有企业名称 | 允许总结；涉及客户报告、工商查询或销售建议时要求确认 | “材料中未识别到明确的企业名称，请补充本次分析的客户名称。” |
| 多文件内容冲突 | 暂停原任务，单独返回冲突 Follow up，列出冲突内容、文件名和页码；用户确认后才继续任务 | “文档 A 显示公司 A 属于物流行业，文档 B 显示公司 A 属于产品平台行业。请选择：物流行业／产品平台行业。” |
| 用户输入与材料无关 | 不调用材料分析能力，执行用户文字任务 | 不额外提示文件异常，直接返回用户所查询的结果 |

Website 用于补充上传材料和内部数据中缺少的公开信息，可查询企业信息、企业痛点、行业背景和行业画像。
