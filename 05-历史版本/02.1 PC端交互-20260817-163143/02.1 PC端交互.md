# 02.1 PC端交互

> PC 端为 3.0 完整形态基准；IPAD / 小程序按 02.2 / 02.3 裁剪。
> 
> 

具体以UI稿为准，demo仅做参考


## 1. 整体页面

|区域|说明|
|---|---|
|左侧导航栏|自上而下：AI销售秘书 icon、搜索框、新建对话、专家技能、我的文件、客户笔记、智能体（金牌陪练、智能讲解）、历史对话、底部用户区|
|中间主区|开场问候 + 统一任务输入框 + 推荐话术卡（数字人专家分组 tab：推荐 / 物流 / 数智金融 / 生态营销 / 财务）。进入对话后此区为消息流|
|右侧产出物面板|默认隐藏。任务产出交付物时自动滑出，宽度 40%，可收起、可手动重开|

全局原则：

- 所有功能入口最终汇入统一对话流，**不存在封闭功能页**；专家 / 技能只是给对话预置上下文

- 任何写入系统的操作必须经过「写操作确认」

- 全局仅一个进行中任务；任务执行中用户不可继续输入，用户可暂停后，再开启新任务对话

## 3. 对话首页

|区域|交互 & 文案|
|---|---|
|开场问候|<ul><li>文案：「Hi {中文名}，今天想从哪个客户开始？」；</li><li>副标题「小助手为你 24 小时随时在线」</li><li>取不到姓名降级为「今天想从哪个客户开始？」</li></ul>|
|任务输入框|<ul><li>placeholder「请输入任务，交给我来帮你完成」；</li><li>支持文件（PDF/Word/PPT/图片，单个≤50M，最多5个）</li><li>语音输入（输入后转文字发送）</li><li>Enter 发送，Shift+Enter 换行；</li><li>上限 2000 字，超限灰提示「内容过长，建议拆分任务」且发送禁用</li></ul>|
|推荐问题|<ul><li>点击不直接发送：话术填入输入框，光标停留，【】占位符高亮；</li><li>未替换占位符点发送给轻提示；</li><li>「换一批」刷新，首期推荐问题由产品提供15条，每次展示3条</li></ul>|
|文件上传|<ul><li>支持 PDF / Word / PPT / 图片；单个 ≤50M，最多 5 个；</li><li>超限 toast「单个文件不能超过 50M」/「最多上传 5 个文件」；</li><li>上传中显示进度，可取消；</li><li>解析失败见 6.1</li></ul>|
|对话框数字人专家选择|<ul><li>按钮文案：「选择专家」</li><li>下拉能力选择框</li><li>数字人专家名称</li><li>介绍（超过字数...显示）</li></ul>|
|数字人专家卡片|<ul><li>每位专家卡：形象位 + 名称 + 一句话介绍 + 能力标签；</li><li>点击进入统一对话流，不是封闭功能页；</li><li>专家选择只影响推荐问题，对话中可自然切换任务，不需要退出重选</li></ul>|
|底部文案（对话中也要显示）|AI生成内容仅供参考，重要决策请结合实际情况判断|

## 4. 对话

|区域|交互 & 文案|
|---|---|
|复合任务展示|<ul><li>复合任务展示：理解的目标 + 步骤链，随执行逐步点亮；</li><li>单步简单任务不展示计划，直接执行</li><li>任务执行中，转圈；执行完成后，✅；步骤中需用户确认的，则暂停；确认后则继续</li></ul>|
|深度思考|流式展出，完毕默认收起，可点开回看|
|过程提示|「读取资料中…」「分析资料中…」「检索知识库中…」「调用 三查一宝...」「调用 企业地图...」「联网搜索...」，与实际执行阶段对应，不要假的 loading 文案|
|中断|流式输出期间展示「停止」按钮；点击后保留已生成内容，尾部标注「已停止生成」|
|澄清交互|<p>点选卡片给算出来置信度高的选项（如同名公司三选一），其他场景可复用，比如知识库识别多个相似的知识等等</p><ul><li>选中后卡片置灰保留，标注用户选择，作为对话记录一部分</li></ul>|
|确认卡|<ul><li>AI 预填关键字段</li><li>主按钮「确认并继续」；点任一字段一下即可修正；修正后重新规划后续步骤，已点亮步骤链重置</li><li>不同场景确认卡片不一样，请根据具体需求出卡片内容</li></ul>|
|产出物面板|<ul><li>生成报告时右侧自动打开；</li><li>结构化卡片分区；</li><li>顶部操作：收藏 / 下载 pdf / 发邮箱；</li><li>可收起重开</li><li>产出物自动存入我的文件</li></ul>|
|写操作确认（是否可以和crm联动）|<ul><li>一切写入 CRM 系统的操作：录商机、录线索、更新客户信息等</li><li>确认卡展示将写入的全部字段 + 文案「以下字段将写入系统，确认后才会真正执行」+ 确认 / 取消</li><li>写入成功：卡片变更为成功态 + 「已写入，可在 CRM 中查看」；写入失败：「写入失败，系统未做任何变更，请稍后重试」，保留确认卡可重试</li><li>确认前每个字段可点击修改</li></ul>|
|复制、点赞、点踩、重新生成|<ul><li>需意图澄清以及用户确认的节点，下方不出这些按钮</li><li>大模型有输出实际内容，不论是否出完都会有这些按钮</li><li>复制</li><li>复制该条消息纯文本（保留段落与换行，去除 markdown 标记）；含产出物的消息只复制消息正文，产出物走面板内的下载入口</li><li>toast「已复制」</li><li>点赞 / 点踩</li><li>点赞与点踩互斥单选；已点赞再点踩 → 取消点赞、记录点踩，反之同理</li><li>再次点击已选中项即取消，同步取消埋点记录（上报取消事件，不物理删除）</li><li>点击即高亮，无弹层，静默埋点</li><li>点击即高亮 + 弹窗原因选项框</li><li>标题「告诉我哪里不好，我会改进」</li><li>内容不准确 / 没理解我的问题 / 答非所问 / 内容太啰嗦 / 其他；多选；选「其他」展开文本框，placeholder「请告诉我具体原因（选填）」，上限 200 字</li><li>按钮「提交」；提交后 toast「感谢反馈」，选项框收起，点踩 icon 保持高亮</li><li>点击空白处 / 收起按钮直接关闭：仅记录点踩行为，不记录原因；点踩 icon 仍保持高亮，再次点击 icon 可重新展开选项框补填</li></ul>|
|Followup question|根据用户的上下文，推荐最匹配的三个问题，点击后可一键发送|

## 5. 状态与异常

|场景|兜底文案|
|---|---|
|**任务失败 / AI 执行异常**|抱歉，当前任务处理未完成，请稍后重试。您也可以换一种方式描述问题，我会继续帮您处理。|
|**多步骤任务部分完成**|已完成部分信息整理，但部分数据获取失败，暂时无法生成完整结果。您可以稍后重试，我会继续基于已有结果处理。|
|**任务超时**|当前处理时间较长，暂未完成分析。您可以稍后重试，或简化问题描述重新发送，我会继续为您处理。|
|**知识检索无结果**|当前知识库中没有匹配的内容。您可以补充更具体的产品、业务场景或关键词，我会继续帮您查询。|
|**网络异常**|当前网络连接异常，暂时无法完成请求。您的输入内容已保留，请重试。|
|**登录失效**|前登录状态已失效，请重新登录后继续使用。|
|文件解析失败|「{文件名}」解析失败，可能是文件损坏或格式不支持。您可以重新上传，或换一个文件试试。|
|语音识别失败|没有听清，请重试，或直接输入文字。 |
