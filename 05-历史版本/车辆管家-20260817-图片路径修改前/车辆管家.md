| # | 边界 |
| --- | --- |

### 4.2 车辆 对比 场景

#### 4.2.1 会话全局序号与对比池

**路径1 明确字段**：帮我对比xx 和xx（有唯一值），直接出对比方案

**路径2 指代消解**：用户问「推荐一款 30 万以内的 LNG 牵引车」→ 出一款推荐→ 用户再问「再推荐一款别的品牌」→ 出一款产品→ 用户接着问「对比这两款」或直接打字"对比一下"→ **不弹澄清**，思考过程里会明说"对比池里两款聚焦车型，指代明确，直接出对比"  
**路径3 多车澄清**：询问30万以内的牵引车，出了列表 在列表中可以进行选中对比

**路径4 多车澄清**：用户先查一批车（列表A），再查一批车（列表B），然后说「对比第一个列表的第几个和第二个列表的第几个」。

新增：对比池，当对比需求勾选时出现，可供用户进行选择对比，不猜用户具体是想要什么对比，仅在点选单个车辆信息后进行展示。

| # | 规则 |
| --- | --- |
| 1 | 序号为会话级全局 ID：可夸对话勾选对比池 |
| 2 | 对比池 = 会话级勾选状态，容量 2，跨列表共享：在列表A勾 1 台、列表B勾 1 台，效果等同于同列表勾 2 台 |
| 3 | 池非空时，输入框上方常驻对比栏：「对比池：③ 天龙VL × ⑩ 漢風G5 × [开始对比]」，单项可删；池为空时对比栏隐藏 |


#### 4.2.2 对比场景交互

| 路径 | 交互 | 规则 |
| --- | --- | --- |
| 勾选确认 | 列表勾选 + 底部「对比已选（n/2）」 | n=2 激活；n=1 点击 toast「再选一款即可对比」；勾选第 3 台时 toast「本期最多对比 2 款，可先取消一款」且勾选不生效 |

指代解析失败（「对比那两个绿的」）→ 澄清意图。

### 4.4 金融 方案 场景

[车辆管理平台-AI智能体金融报价](https://my.feishu.cn/wiki/QuSiwTLYLieJrQkwZHycUswdngh) 具体生成的报价规则 请参考这个文档

#### 4.4.1 唯一方案原则

约束：

| # | 规则 |
| --- | --- |
| 1 | 模型不参与任何金额计算，不允许对引擎输出做改写、取整、换算；数据库返回什么渲染什么 |
| 2 | 用户口头议价（「利率能不能低点」「首付 5 万行不行」）不改变方案输出，回复统一话术：「金融方案按公司统一规则计算，如需特殊申请请联系金融业务线对接人」 |
| 3 | 同一车辆重复请求方案，结果必须一致（引擎无随机性）；规则参数变更只通过配置中心，变更留痕 |

#### 4.4.2 生成入口与多车逻辑

| 场景 | 规则 |
| --- | --- |
| 单车查询 / 详情卡 | 卡片主按钮「生成金融方案」 |
| 多车查询结果 | 不自动生成任何方案；每行按钮按需触发，点哪台生成哪台 |
| 生成中 | 该行按钮转 loading，其他行按钮可继续点击（并行生成）；生成完成后按钮变为「查看方案」 |
| 产出物承载 | 每份方案进右侧产出物面板独立 tab，tab 名 = 车辆型号；面板顶部操作同 4.6（收藏 / 下载 pdf / 发邮箱） |
| 方案类型判定 | 车辆型号在合营车型表内 → 方案页展示两个 tab：「标准方案」「合营购车方案」，默认标准方案；不在表内 → 仅标准方案 |

#### 4.4.3 金融方案生成格式


##### 1 标准化方案（适用于任何车辆）

**方案要素区（表格上方）**：车辆型号、车辆售价、购置税、预估保费。展示金额，**不展示任何比例与利率**。

**方案矩阵**：行 = 期数（24 / 36 / 48），列 = 首付档位 1\-6（表头展示计算后的首付金额，如「首付一 ¥58,600」，不展示档位比例），单元格 = 月还款 \+ 总成本两行。

**计算规则（报价引擎实现，前端不感知，此处为引擎侧需求）**：

| 场景 | 规则 |
| --- | --- |
| 单车查询 / 详情卡 | 卡片主按钮「生成金融方案」 |
| 多车查询结果 | 不自动生成任何方案；每行按钮按需触发，点哪台生成哪台 |
| 生成中 | 该行按钮转 loading，其他行按钮可继续点击（并行生成）；生成完成后按钮变为「查看方案」 |
| 产出物承载 | 每份方案进右侧产出物面板独立 tab，tab 名 = 车辆型号；面板顶部操作同 4.6（收藏 / 下载 pdf / 发邮箱） |
| 方案类型判定 | 车辆型号在合营车型表内 → 方案页展示两个 tab：「标准方案」「合营购车方案」，默认标准方案；不在表内 → 仅标准方案 |

##### 2 合营购车方案（仅限合营车型表内车辆）

**前置澄清**：合营方案首付与《合营购车车型和金融方案》表按客户等级（S级 / A级）区分。生成前走 4\.2 澄清卡：「该车支持合营购车，你的客户是哪个等级？」选项：S级客户 / A级客户 / 不确定；选「不确定」则两个等级方案并排展示。

**方案表**：（按照用户提供的表进行匹配，匹配上的则有，没有则不展示）

| 列 | 数据来源 |
| --- | --- |
| 首付（提车款项） | 合营车型表按车型 × 客户等级取值 |
| 1-36期月还款 | 合营车型表取值 |
| 37-48期月还款 | 合营车型表取值 |
| 总成本 | 首付 + 1-36期月还款 × 36 + 37-48期月还款 × 12（引擎计算） |

##### 3 免责与提示文案

| 位置 | 文案 |
| --- | --- |
| 方案页底部（常驻） | 以上方案按公司统一规则测算，仅供参考，不构成合同要约；最终以合同签署为准。 |
| 保费字段旁 | 保费为系统估算，最终保费以保险公司报价为准。 |

#### 4.4.4 按金额测算金融方案


当用户只给金额时，按照标准化方案公式输出金融方案，按照表格输出即可。直接输出到对话里，不保存到产出物里。

| 零结果 | 「当前条件下没有查到相关车型。您可以放宽【价格/马力/驱动】检索需求后，再发起查询」——放宽维度由检索层返回最接近命中的差异条件 |
| 条件矛盾（「500马力的4×2」不存在组合） | 同零结果兜底 |
| 单侧对比分组标题 | 你说的「{型号}」有 {n} 款，选一款： |
| 双侧对比分组标题 | 同上，两组各一行 |
| 已锁定标记 | 已锁定 |
| 一侧检索不到 | 「{型号}」没有检索到相关车型，您可以放宽【价格/马力/驱动】检索需求后，再发起查询 |
| 两侧都检索不到 | 当前条件下没有查到相关车型。您可以放宽【价格/马力/驱动】检索需求后，再发起查询（同 §6 零结果兜底） |
| 指代解析失败 | 澄清：「你想对比哪两款？请勾选后进行对比」 |
| 勾选第 3 台 | toast「本期最多对比 2 款，可先取消一款」 |
| 仅勾 1 台点对比 | toast「再选一款即可对比」 |
| 金额方案无法生成（如「出个便宜车的方案」无金额） | 澄清：「请告诉我大概的预算是多少？我可以跟进价格生成金融方案」 |
| 金额测算后追问对比（「跟第3个比比」） | 金额测算方案不是车辆，不进对比池；回复「无法按照金融方案进行对比，请查询具体车辆信息后进行对比」 |
| 车辆图片 | 取到则展示，取不到不展示 |
| 埋点 | 列表曝光、勾选、对比触发路径（A/B/C/D 分开记）、金融方案按钮点击、只看差异开关，均带 vehicle_id / session_id （后期到全部埋点 一块会重新梳理一遍） |
