# 销售秘书3.0项目规则

## 文件保存规则

- 在“销售秘书3.0”中创建任务时，所有生成和交付文件直接保存到 `/Users/liujun/Documents/销售秘书3.0`，不得只保存在临时目录、缓存目录或 ChatGPT 项目镜像中。
- 可运行的演示版本、原型和 Demo 配套文件保存到 `01-Demo/`。
- 最终需求文档、Markdown 文档及其配套资源文件夹保存到 `02-需求文档/`。
- 用户提供的原始 Word、PDF、Excel、Markdown 等参考文件，若要求归档或复制，保存到 `03-原始资料/`；不要修改原始文件。
- 独立图片、截图、流程图和设计图保存到 `04-图片资源/`。
- 修改已有正式文件前，将原版本复制到 `05-历史版本/`，文件名增加日期时间，避免覆盖历史版本。
- Markdown 文档引用的配套图片应放在与 Markdown 同级的 `<文档名>_assets/` 文件夹中，并使用相对路径引用。
- 交付前检查最终文件及其配套资源确实存在，并向用户提供正式目录中的文件链接。
- 除非用户另行指定，生成文件时按上述目录自动分类，无需再次询问保存位置。
- 每次完成文件生成、修改或整理并通过交付检查后，自动将本次变更提交到本目录的 Git 仓库；提交说明使用简洁中文概括本次交付。
- 若已配置 Git 远程仓库，提交后自动推送到远程；若尚未配置远程仓库，则保留本地提交并提醒用户本地 Git 不能替代异地备份。
- 不得将密码、访问令牌、私钥或其他敏感凭据提交到 Git。

## 目录用途

- `01-Demo/`：可运行的演示版本、原型及其配套文件。
- `02-需求文档/`：最终需求文档、Markdown 和配套资源。
- `03-原始资料/`：原始 Word、PDF、Excel 等输入资料。
- `04-图片资源/`：独立图片、截图、流程图和设计图。
- `05-历史版本/`：修改前的旧版本。
