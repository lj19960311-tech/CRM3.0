# 车辆信息跳转商品信息/车辆政策

## 一. 需求背景

用户在销售秘书中查看车辆信息时，需要通过**车辆型号**快速进入车辆商品超市，并直接查看该车型对应的照片，减少手动搜索车型和查找照片的操作。

## 二. 需求目标

支持用户点击车辆型号，打开车辆商品超市中对应车型的商品详情页。

## 三. 功能需求

### 3.1 PC端需求

#### 3.1.1 车辆型号可点击【有图没图是谁来判断】

在PC端中：

- 商品超市有数据的，则车辆型号为蓝色字体展示；没有数据的则保持黑色。
- 列表字段顺序：序号、车辆品牌、销售指导价、车辆型号......
- 用户点击车辆型号后，在新标签页打开车辆商品超市。
- 跳转过程中需携带当前车型对应的商品标识，确保打开正确车型。

链接示例（链接为测试环境）：

<https://3u.wanlianyida.com/vehicle-supermarket/product/2076575392323182593>

#### 3.1.2 自动定位车型详细页面

- 跳转之后，直接打开商品详情页。

推荐深链格式：

```text
https://3u.wanlianyida.com/vehicle-supermarket/product/{product_id}?focus=image&imageId={image_id}&source=sales_secretary
```

#### 3.1.3 交互流程

```text
用户点击车辆型号
    ↓
销售秘书根据 product_id 和 image_id 生成商品深链
    ↓
新标签页打开车辆商品超市
    ↓
商品超市加载对应车型商品详情
```

### 3.2 PAD端和小程序需求【需要再次评审】

#### 3.2.1 车辆型号可点击

在PAD和小程序端中：

- 商品超市有数据的，则车辆型号为蓝色字体展示；没有数据的则保持黑色。
- 列表字段顺序：序号、车辆品牌、销售指导价、车辆型号......
- 用户点击车辆型号后，跳转到**【工作台 - 车辆政策】中的车辆详细页面；**
- 跳转过程中需携带当前车型对应的商品标识。

#### 3.2.2 自动定位车辆详细页面

- 跳转之后，直接打开商品详情页；
- 打开正确车型详细页面之后，点击“返回”可以回到销售秘书3.0初始页面（最好调研是否回到原始对话）。

#### 32.3 交互流程

```text
用户点击车辆型号
    ↓
跳转到【工作台 - 车辆政策】对应车型商品详情
    ↓
在【商品详情页面】点击返回
    ↓
销售3.0页面
```

## 四. 异常处理

| 异常情况 | 处理方式 |
| --- | --- |
| 商品不存在或已下架 | 不支持跳转 |

## 五. 数据要求

销售秘书需要获取以下数据：

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `source.id` | string | 是 | 车辆信息的唯一标识。 |
| `vehicle_model` | string | 是 | 页面展示的车辆型号。 |
| `product_id` | string | 是 | 对应车辆商品超市（小程序和PAD中车辆政策）中的商品唯一标识。 |
| `image_id` | string | 否 | 需要直接展示的车型照片唯一标识。 |

数据映射要求：

- `source.id`、`product_id` 和 `image_id` 必须属于同一车型。
- 不得通过车辆型号名称临时推断 `product_id`。
- 商品超市（小程序和PAD中车辆政策）需校验 `image_id` 是否属于当前 `product_id`，避免展示错误车型照片。
