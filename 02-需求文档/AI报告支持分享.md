# 1 AI报告支持分享

## 一. 需求背景

在物流产品专家和车辆专家中生成的 AI 报告，可以通过 PC、PAD 或小程序将报告快速分享给客户。

## 二 .  需求目标

- PC、PAD、小程序均支持分享本人生成的 AI 报告。
- 每份报告拥有一个当前有效的唯一分享链接及对应二维码。
- 同一份报告跨端分享时，复用当前有效链接和二维码。

## 三. 用户角色与权限

| 用户角色 | 权限 |
| --- | --- |
| 报告生成人 | 创建分享链接和二维码，并进行复制、下载或保存 |
| 报告接收人 | 在链接有效时查看只读报告 |

### 4.1 分享功能交互表

| 功能节点 | 触发条件 | 展示及交互规则 | 结果与反馈 |
| --- | --- | --- | --- |
| 点击分享图标 | 用户在报告详情页点击分享图标 | 打开“分享”弹窗；选择有效期、点击生成分享链接按钮，生成链接、二维码、复制及下载操作 | 已有链接时，在同一弹窗内直接展示原链接、二维码及有效期 |
| 弹窗基础信息 | 打开分享弹窗 | 标题为“分享报告”；展示报告名称“鞍山钢铁 · 物流综合解决方案”、报告生成时间（YYYY-MM-DD HH:mm）、有效期选择区及链接结果区 | 右上角关闭图标或点击遮罩可关闭弹窗；关闭不影响已生成的链接和二维码 |
| 首次选择有效期 | 报告尚未生成分享链接 | 默认选中“永久有效”，可切换为“7 天有效”；未生成前不展示正式链接和二维码 | 底部主按钮展示“生成分享链接” |
| 生成分享链接 | 用户点击“生成分享链接” | 系统根据所选有效期生成唯一链接和二维码；按钮进入加载状态并显示“生成中…”，不可重复点击；有效期选择区保持在当前弹窗内 | 成功后，链接、二维码、“复制链接”和“下载/保存二维码”直接在当前弹窗下方展开，不跳转页面；有效期变为只读；失败时提示“分享链接生成失败，请重试”并恢复按钮 |
| 永久有效 | 首次生成时选择“永久有效” | 作为默认选项；链接不因时间自动失效 | — |
| 7 天有效 | 首次生成时选择“7 天有效” | 从链接生成成功时间开始计算连续 7×24 小时；展示具体截止时间，如“有效期至 2026-08-18 15:30” | 到期后链接和二维码均不可访问；提示“报告链接已过期，请联系分享人重新获取” |
| 已生成链接 | 再次打开分享弹窗 | 直接展示原有效期、完整链接和二维码；有效期只读，不可修改 | 本期不支持撤销或重新生成链接；弹窗不展示相关按钮 |
| 分享链接 | 链接生成成功 | 每份报告仅生成一个链接；链接与报告、生成人、生成时间及有效期绑定；使用不可预测的随机 Token 和 HTTPS；URL 不包含姓名、手机号、客户名称等敏感信息 | 链接格式示例：https://域名/report/share/{随机Token} |
| 二维码 | 链接生成成功 | 二维码内容为完整分享链接；下方展示“扫码查看报告”和有效期；根据弹窗宽度自适应；PAD、小程序支持点击放大 | 扫描二维码与复制链接打开同一份报告 |
| 复制链接 | 用户点击“复制链接” | PC、PAD、小程序均将完整链接写入剪贴板 | 成功提示“链接已复制”；失败提示“复制失败，请手动复制链接” |
| PC 下载二维码 | 用户点击“下载二维码” | 下载 PNG 格式二维码图片 | 图片包含报告名称、二维码、“扫码查看报告”和有效期 |
| PAD 保存二维码 | 用户点击“保存二维码” | 调用设备支持的图片保存能力 | 保存失败时保留复制链接作为兜底方式 |
| 小程序保存二维码 | 用户点击“保存二维码” | 申请相册权限并保存图片；用户拒绝时提示前往设置开启权限 | 保存失败时保留复制链接作为兜底方式 |

### 4.2 报告查看页

- 接收人点击链接或扫描二维码后进入只读报告页。
- 页面展示“鞍山钢铁 · 物流综合解决方案”的完整报告内容。
- 页面不展示物流产品专家后台导航、编辑入口、“发送到邮箱”及分享图标。
- 页面兼容手机、PC、PAD浏览器及小程序承载页。

### 4.3 三端交互差异

| 功能 | PC | PAD | 小程序 |
| --- | --- | --- | --- |
| 分享入口 | “发送到邮箱”右侧的分享图标 | 与 PC 一致 | 报告顶部分享图标 |
| 分享容器 | 居中弹窗 | 横屏弹窗；竖屏底部抽屉或全屏层 | 底部弹层或独立分享页 |
| 二维码 | 展示、下载 | 展示、放大、保存 | 展示、放大、保存相册 |
| 复制链接 | 支持 | 支持 | 支持 |
| 报告查看 | 响应式网页 | 横竖屏响应式网页 | 小程序承载页或内嵌网页 |

## 五. 异常提示

| 场景 | 提示文案 |
| --- | --- |
| 分享链接生成失败 | 分享链接生成失败，请重试 |
| 链接不存在 | 报告链接无效，请联系分享人重新获取 |
| 7 天链接已过期 | 报告链接已过期，请联系分享人重新获取 |
| 二维码保存失败 | 二维码保存失败，请重试 |
| 网络异常 | 加载失败，请检查网络后重试 |

## 六. 安全要求

- 服务端必须校验当前用户对内部报告详情页的访问权限。
- 分享链接使用不可预测的随机 Token，并全程使用 HTTPS。
- URL 不得携带姓名、手机号、身份证号等敏感信息。
